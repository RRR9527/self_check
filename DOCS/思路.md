# 自检系统大纲

### 设计目的

在上电之初进行全方面的整车检查，以避免接线错误/硬件故障等等低级错误耽误时间或误导大家以为代码出错。

### 触发方式

上电自动执行一遍，在进入RTOS之前直接执行一遍。中途出故障在F4上RESET也能触发。

不行，考虑发现一些东西完全没办法闭环，只能依赖能工智人。所以，LED这样的应该要有响应

我是傻*。明明有流水灯一直运行，LED和蜂鸣器完全可以不检查。但写都写了懒得删

### 检查内容

按照顺序：

- LED和蜂鸣器 （后续计划用这两个报错/报平安。如果这两个直接错了后续啥都干不了）
- 通信。CAN/串口；主从版之间/从板和电机之间
- 传感器
- 电磁阀，气泵
- 电机

### 注意事项

- 安全优先。电机电流限幅尽可能调小。位置模式，速度模式不测试大位置/大速度；运行之前蜂鸣器长鸣警告
- 超时自动报错
- 和主程序写在一起的代码，不需要自检完重新烧录代码
- 不需要连接上位机查看报错。可以靠LED和蜂鸣器的组合技传递信息（摩斯密码？约定的协议？）
- 自检完成后等待蓝牙信号（或者其他物理信号）再开始后续正常程序
